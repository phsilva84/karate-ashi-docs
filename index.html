Política de Privacidade — Karate-Ashi rclone

Última atualização: 14 de setembro de 2026

1. Sobre este aplicativo

O aplicativo Karate-Ashi rclone é usado exclusivamente pelo proprietário para automatizar a sincronização de arquivos do Dojo Karate-Ashi entre o Google Drive e o GitHub Actions (processamento de avaliações de exame).

2. Dados acessados

O aplicativo acessa somente as pastas do projeto Karate-Ashi no Google Drive: gabaritos, cadastros e relatórios de avaliação.

3. Uso dos dados

Os dados são utilizados exclusivamente para leitura e escrita dos arquivos do projeto. Nenhum dado é compartilhado com terceiros, vendido ou utilizado para publicidade.

4. Armazenamento e segurança

Os arquivos permanecem armazenados no Google Drive do proprietário. O acesso do rclone é feito via OAuth com tokens que podem ser revogados a qualquer momento pelo proprietário.
